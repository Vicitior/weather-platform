## 三、parquet 字段说明

### weather_data（每个 station_<id>.parquet）
| 列名 | 类型 | 说明 |
|---|---|---|
| `ts` | timestamp[us, UTC] | 原始时间戳（UTC，与源库一致） |
| `ts_bj` | timestamp[us] | **北京时间**（ts + 8h，日常分析用这个） |
| `avg_temperature` | double | 平均气温 ℃（含哨兵值，见体检报告） |
| `max_temperature` | double | 最高气温 ℃ |
| `min_temperature` | double | 最低气温 ℃ |
| `avg_humidity` | int64 | 平均相对湿度 % |
| `precipitation` | double | 降水量 mm（含天气现象编码，见体检报告） |
| `avg_wind_speed` | double | 平均风速 m/s |
| `sunshine_hours` | double | 日照时数 h |
| `file_path` | string | 源 Excel 在 OSS 上的路径 |
| `user_id` | int64 | 上传用户 ID |
| `user_nickname` | string | 上传用户昵称 |

> **注意**：源库子表 `SELECT *` 不返回 TAG 列（`station_id` / `station_code` / `uploaded_at`）。本地镜像里 `station_id` 由文件名 `station_<id>.parquet` 解析得到，在 `local_lab.py` 的 `weather` 视图中已自动补上；站点维信息（省/站名/经纬度/海拔）通过 `weather_joined` 视图关联得到。

## 四、怎么用

### 1) 命令行单条查询
```powershell
python "D:\Android PDF\local_lab.py" -q "SELECT * FROM weather LIMIT 10"
```

### 2) 交互式
```powershell
python "D:\Android PDF\local_lab.py"
lab> SELECT station_id, count(*) n FROM weather GROUP BY 1 ORDER BY n DESC LIMIT 10;
lab> .views
lab> .cols weather_joined
lab> .quit
```

### 3) Python 里用
```python
import sys; sys.path.insert(0, r'D:\Android PDF')
import local_lab
df = local_lab.q('SELECT province, count(*) FROM weather_joined GROUP BY 1')
```

### 4) 内置视图
| 视图 | 内容 |
|---|---|
| `weather` | TDengine 全部 876 个子表（1669 万行），**含哨兵值**，带 station_id |
| `weather_ok` | 已按物理合理范围过滤哨兵/异常值，**做统计推荐用这个** |
| `stations` | MySQL weather_station_info，909 个站点维表 |
| `weather_joined` | weather + 站点维表关联宽表（带省/站名/经纬度/海拔） |
| `mysql_<表名>` | MySQL 的 31 张表，逐表一个视图，如 mysql_raster_asset |

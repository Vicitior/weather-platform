二、parquet 字段说明

列名类型说明
tstimestamp[us, UTC]原始时间戳（UTC，与源库一致）
ts_bjtimestamp[us]<b>北京时间</b>（ts + 8h，日常分析用这个）
avg_temperaturedouble平均气温 ℃（含哨兵值）
max_temperaturedouble最高气温 ℃
min_temperaturedouble最低气温 ℃
avg_humidityint64平均相对湿度 %
precipitationdouble降水量 mm（含天气现象编码）
avg_wind_speeddouble平均风速 m/s
sunshine_hoursdouble日照时数 h
file_pathstring源 Excel 在 OSS 上的路径
user_idint64上传用户 ID
user_nicknamestring上传用户昵称
注意：源库子表 SELECT * 不返回 TAG 列（station_id/station_code/uploaded_at）。本地 station_id 由文件名 station_<id>.parquet 解析得到，local_lab.py 的 weather 视图已自动补上；站点维信息通过 weather_joined 关联得到。

三、怎么用

命令行单条查询

python "D:\Android PDF\local_lab.py" -q "SELECT * FROM weather LIMIT 10"

交互式

python "D:\Android PDF\local_lab.py"
lab> SELECT station_id, count(*) n FROM weather GROUP BY 1 ORDER BY n DESC LIMIT 10;
lab> .views
lab> .cols weather_joined
lab> .quit

Python 里用

import sys; sys.path.insert(0, r'D:\Android PDF')
import local_lab
df = local_lab.q('SELECT province, count(*) FROM weather_joined GROUP BY 1')
